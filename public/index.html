              Nouveautés

              Bienvenue dans ChaosClip

              1. Ouvre une vidéo : colle un lien (Ctrl+V n'importe où) ou glisse un fichier dans la fenêtre.
              2. Choisis le passage : sur la première image appuie sur I, sur la dernière sur O. Glisse sur la vidéo pour recadrer.
              3. Exporte avec Ctrl+Entrée, puis Copier et Ctrl+V dans Discord.

              Toutes les touches : bouton ? en haut à droite. Clic droit sur la frise ou la vidéo pour les actions courantes.

              1. Ouvre une vidéo : colle un lien, choisis un fichier, ou touche « Partager » dans YouTube ou ton navigateur.
              2. Choisis le passage : sur la frise, glisse les deux poignées orange. Pour recadrer, touche « Recadrer » sous la vidéo.
              3. Exporte, puis touche Partager pour l’envoyer dans Discord.

              Appui long sur la frise ou la vidéo pour les actions courantes, sur un bouton pour son explication. Pince la frise ou la vidéo pour zoomer.

              Discord refuse les fichiers trop lourds : avec une limite, ChaosClip réduit l’export jusqu’à ce qu’il passe. Elle se change ensuite sous « Sortie ».

              Projets

              Un projet garde la vidéo, la sélection, les segments, le recadrage, les textes et les réglages.

                Assembler des images

                Choisis plusieurs images : elles deviennent une vidéo, que tu découpes et exportes comme les autres. Glisse pour changer l'ordre.

                  Capture d'écran

                  Choisis un écran ou une fenêtre. La capture devient une source : recadre ensuite la zone voulue.

                  Comparaison

                  A = réglages gardés, B = réglages actuels. Change un réglage puis relance pour comparer.

                    Aide-mémoire

                    Souris : molette sur la vidéo = image par image, Ctrl + molette = zoom, glisser = recadrer. Frise : clic = se placer, poignées = début et fin, Ctrl + glisser dans la sélection = la déplacer, Maj + glisser = nouvelle sélection (aimantée aux plans et marqueurs, Alt pour l'éviter). Clic droit : actions courantes.
